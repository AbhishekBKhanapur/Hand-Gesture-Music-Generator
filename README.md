# Hand Gesture Music Generator

## Description
The Hand Gesture Music Generator allows users to create and control music in real-time using hand gestures. Using a webcam, hand movements are detected and mapped to musical notes, enabling an interactive and innovative way to compose music without physical instruments.

## Features
- Generate music using hand gestures
- Real-time detection and sound playback
- Supports multiple gestures for different notes or instruments
- Interactive and fun for learning and music creation

## Tech Stack
- Python
- OpenCV (for hand tracking)
- MediaPipe (for gesture recognition)
- PyGame / PyAudio (for sound generation)
- NumPy (for calculations)
